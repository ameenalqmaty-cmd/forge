# Forge — مصنع التطبيقات الشخصي

قالب أساسي يبني منه Claude أي تطبيق أو موقع بواجهة احترافية من أول مرة.

- **ثيم واحد لكل تطبيق من خمسة:** هادئ احترافي، مرح ملوّن، فاخر، تعليمي دافئ، ألعاب نيون.
- **غلاف متجاوب:** شريط سفلي في الهاتف، وقائمة جانبية في التابلت والكمبيوتر.
- **إصلاحات جاهزة:** لا شريط تمرير ولا تمرير أفقي، واحترام النتوء وحواف الشاشة، ولا تكبير مفاجئ في الحقول.
- **فحص آلي:** `npm run qa` يلتقط صوراً على ٥ مقاسات، فاتح وداكن، ويفشل عند أي خروج عن الشاشة.
- **قواعد Claude:** في `CLAUDE.md`، وتشمل تعريف «الانتهاء» وما يُنفَّذ دون طلب.

```bash
npm install
npm run dev        # التطوير
npm run qa         # الفحص البصري الآلي
npm run build      # البناء
```
